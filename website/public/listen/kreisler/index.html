Listening demo · Kreisler, Pierrot’s Dance Song

Hear it on the faceplate

Press play, then switch with the faceplate’s own keys: REPAIRED for the declicked audio, BYPASS for the original, CLICKS to hear only what was removed. All three play in sync, so a key flips the sound mid-phrase. The meter and strip chart follow the engine’s real list of repairs.

A note on this example. 2ndPressing’s results are much more noticeable on modern recordings. Copyright limits what can be published here, so this demo uses a 78 rpm record made before 1926, which is in the public domain.
0:00.0 / 0:30 Hearing: Repaired

How to listen

  • Headphones help. Flip BYPASS on and off while it plays (or press B); C toggles Repaired and Clicks only; Space plays and pauses.
  • Amber ticks above the waveform mark each of the 1207 repairs. Click or drag the waveform to jump.

How it was made

The real 2ndPressing engine (ClickNet R2, sensitivity 50 %, percussion protection Off) processed this 30.0 s clip at 48.0 kHz. Original, repaired and clicks-only were rendered with the same latency compensation, so they line up sample for sample, then encoded identically as AAC. Switching uses a 10 ms crossfade, as the plugin does. The sensitivity knob and protection keys show the settings this clip was processed with; they don’t reprocess audio in the browser. Recording: Fritz Kreisler (violin) and Carl Lamson (piano), Korngold arr. Kreisler, “Pierrot’s Dance Song”, Victor 1062A (1924). Transfer: Internet Archive, Great 78 Project. Public domain.
