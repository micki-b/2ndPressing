What the installer adds

  • 2ndPressing app. Play a turntable through any audio interface and hear it cleaned live, no DAW needed.
  • Audio Unit (Mac only), for Logic Pro, GarageBand and other AU hosts. It installs the CLAP plugin too, which it loads.
  • VST3 and CLAP plugins, for other DAWs.

On the Mac, choose Customize on the Installation Type step to pick only some of these; on Windows, untick what you don’t need on the Choose Components page.

Install on a Mac

  1. Open 2ndPressing-0.1.1.pkg and follow the installer. It asks for your Mac password because plugins go into the shared Library folder.
  2. App: open 2ndPressing from Applications. The first time, macOS asks whether it may use the microphone. Allow it, or the app can’t hear your audio interface.
  3. Plugins: restart your DAW. In Logic Pro the plugin is under Audio Units › 2ndPressing › 2ndPressing Declicker.

Install on Windows

  1. Open 2ndPressing-0.1.1-windows-x64-setup.exe. The installer isn’t code-signed yet, so Windows shows “Windows protected your PC”: click More info, then Run anyway. Approve the administrator prompt.
  2. App: open 2ndPressing from the Start menu. If Windows asks about microphone access, allow it.
  3. Plugins: restart your DAW and rescan plugins if it doesn’t find them. They are in Common Files\VST3 and Common Files\CLAP.

Windows testers wanted. This is the first Windows build and it has had very little testing on real PCs, so any report, even “it installed and worked”, helps.

Good to know in this beta

  • Delay. Percussion protection is set to Extended, which looks about 2 seconds ahead, so you hear the music 2 s late. DAWs compensate automatically. For live listening in the app, press Off for a 32 ms delay.
  • Sample rates. 44.1 and 48 kHz are the tested rates. Higher rates work but are experimental.
  • In the app, pick your audio interface and the channel pair your turntable is on in the Audio strip under the controls. The status line says what’s wrong if no sound arrives.

Uninstall

Windows: Settings › Apps › 2ndPressing Declicker › Uninstall. It removes the app and both plugins.

Mac: delete these, then restart your DAW:

  • /Applications/2ndPressing.app
  • /Library/Audio/Plug-Ins/Components/2ndPressing Declicker.component
  • /Library/Audio/Plug-Ins/VST3/2ndPressing Declicker.vst3
  • /Library/Audio/Plug-Ins/CLAP/2ndPressing Declicker.clap
  • ~/Library/Application Support/2ndPressing (the app’s saved settings)
