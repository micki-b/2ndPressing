# 2ndPressing logo

The logo is a black moving-magnet cartridge with an amber stylus, on a
Technics SL-1200-style silver headshell and arm. It is a 3D model at true
scale (millimetres), rendered to vector SVG with true perspective:

- **Large logo** (website hero, installer, about box): view V2, three-quarter
  from the front right, 20° above the record, with grooves.
- **Icon** (app icon, favicon): the same model seen straight on, with "2nd"
  on the cartridge front.
- **Header icon** (plugin and app window header, website header): the front
  view without lettering.

| File | What |
|---|---|
| `logo3d/model.py` | The model (cartridge, headshell, finger lift, bayonet connector, locking ring, S-arm, record) and the SVG renderer |
| `logo3d/build3.py` | The review page used to approve the design |
| `export.py` | Writes every asset to where it is used (see its docstring) |
| `out/` | Master files (SVGs, 2400 px PNG, 1024 px app icon, `AppIcon.icns`), regenerated by `export.py` and git-ignored; the copies the products use are committed in their own folders |

Lettering is converted to vector outlines from IBM Plex Sans Condensed
SemiBold (`runtime/crates/pressing-plugin/assets/fonts`), so the SVGs need no
installed font.

## Re-export after a change

```sh
uvx --with fonttools --with pillow python brand/export.py   # needs Google Chrome
website/tools/render_images.sh                                # share image (run from website/)
```

Then rebuild the plugin (`cargo xtask bundle pressing-plugin --release`) and
the app (`crates/pressing-app/macos/bundle.sh`) in `runtime/`, and re-upload
the website.
